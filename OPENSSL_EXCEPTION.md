# OpenSSL 附加许可 / OpenSSL additional permission

## 中文说明

本附加许可依据 GNU AGPL 第 3 版第 7 节授予。

本附加许可仅适用于小仓版权方有权许可的小仓原创材料。你可以将这些材料与小仓 Windows 版 CPython 运行时随附的 OpenSSL 1.1.1 库链接，并分发由此形成的组合。这些库采用原 OpenSSL 和 SSLeay 许可；当前随附版本为 1.1.1t。

本附加许可仅适用于上述 OpenSSL 组合，不授权与任意库或闭源组件链接。AGPL 第 3 版的其他适用义务继续有效，包括与对应源码（Corresponding Source）及远程网络交互有关的义务。

OpenSSL 及其他所有第三方材料仍适用各自的许可。你必须遵守这些许可，并保留其要求的声明。本附加许可不改变第三方材料原有的许可，也不授予小仓版权方无权授予的权利。
