# 小仓 / Cangoo 1.0.0

Windows首版提供密码与加密记事管理、安全体检、密码生成与强度检测、快捷搜索、加密备份恢复及离线中英帮助。提供安装版和便携版。

安装版默认仅当前用户安装；更新沿用原安装范围和目录，更换范围或目录前先卸载并保留数据。便携版需完整解压，更新时保留原data目录和用户数据库。具体步骤见[使用手册](docs/user_guide_zh.md)。发行文件未签名，请从本项目版本页下载并核对SHA-256；校验值不替代代码签名。


## English

The first Windows release includes password and encrypted-note management, security checks, password generation and strength estimates, Quick Bar, encrypted backup and restore, and offline Chinese/English help. Installer and portable editions are available.

The installer defaults to the current user. Updates keep the existing installation scope and directory; uninstall while retaining data before changing either. Fully extract the portable edition and preserve its data folder and databases during updates. See the [user guide](docs/user_guide_en.md). Files are unsigned; download from this project's releases and verify SHA-256. Checksums do not replace code signing.
