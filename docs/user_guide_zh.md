# 小仓使用手册

## 开始使用与数据准备

<h3>准备什么</h3><p>准备一台 Windows 10/11 64 位电脑、可读写的本地目录，以及你能妥善保管的主密码。不同 Windows 版本和显卡的兼容情况需以实际环境为准。</p><h3>第一次打开</h3><ol><li>阅读“软件许可协议”，可直接切换中文或 English（英语）。</li><li>选择“同意并继续”后进入软件；选择不同意或关闭协议窗会退出。</li><li>左侧“帮助”不要求连接数据库。主题、语言和字号可以在“设置”中调整。</li></ol><h3>先认识三种密码</h3><p>主密码用于打开一个数据库；记录密码是你保存的各网站或应用密码；备份密码专门保护导出的备份。它们用途不同，软件不会替你找回遗忘的密码。</p><h3>出错后怎么办</h3><p>若提示无法保存设置，可以重试或退出后重新打开软件。问题持续时，请在项目社区说明错误提示和操作经过；项目地址见“帮助 → 关于”或软件下载页面。请勿提交真实密码、数据库或备份。</p>

## 创建、连接与最近数据库

<h3>创建第一个数据库</h3><ol><li>在连接卡片的“数据库路径”输入一个<strong>尚不存在</strong>的本地文件路径，例如 D:\CangooData\personal.db；先准备好可写目录。</li><li>在“主密码”输入你选择的密码。软件允许空主密码，但为保护数据，建议使用非空且独特的长密码。</li><li>单击“连接 / 创建”，等待连接结果。成功后进入密码库。</li></ol><h3>打开已有数据库</h3><p>单击“浏览数据库”选择已有文件，或在最近使用中选择一项，再输入该库的主密码并连接。最近项的“移除”只移除入口，不删除磁盘文件。切换数据库前请完成或放弃未保存的编辑，并锁定当前数据库后再连接另一库。</p><h3>出错后怎么办</h3><p>主密码错误时按提示核对键盘布局、大小写和目标文件；连续三次错误会锁定该数据库 24 小时，错误次数跨重启和实例累计。锁期结束提供新的三次机会，成功认证重置计数。浏览或最近项的文件已不存在时请重新选择；手动输入不存在的新路径才是创建入口。文件损坏或不可读时保留原文件，核对权限或恢复备份，不反复覆盖尝试。</p>

## 保存与管理密码

<h3>新建与保存</h3><ol><li>连接数据库，在“密码库”单击“+ 新建”。</li><li>在“平台”选择或填写条目名称（例如“示例邮箱”），在“账号”填写登录名（例如 demo@example.invalid），再填写密码、备注和可选 TOTP 密钥。名称必填且在库内精确唯一，其他普通字段可留空。可以使用表单的密码生成按钮；保存前核对目标账号。</li><li>单击保存。成功后条目会出现在列表中；保存失败时按错误提示修改或重试，不把关闭表单当成保存成功。</li></ol><h3>查看、复制、编辑与删除</h3><p>列表与分屏展示同一批记录。用眼睛按钮切换密码显隐，用对应复制按钮复制账号或密码；空字段会提示，不能当成复制成功。编辑会打开独立窗口；保存后回到主界面核对。关闭未保存的编辑时按确认选择继续编辑或放弃。删除必须确认目标，完成后不能靠撤销找回，请先保留备份。</p><h3>验证码</h3><p>若账号支持基于时间的一次性验证码（TOTP），在记录中填写该服务提供的密钥；不要填写当前显示的六位验证码。系统时间不准会影响验证码，登录失败时先核对电脑时间和密钥。</p><h3>长字段与并发修改</h3><p>账号和密码可横向滚动查看尾部，长备注可滚动；必要时用完整内容入口。若另一实例已经修改同一记录，按提示加载最新内容并重新核对；不要认为旧窗口里的内容仍是最新值。</p><p>已启用验证码的记录编辑时，密钥框留空表示保留原密钥；删除应单击“移除现有 TOTP”并保存。密钥不会回显。</p>

## 搜索、排序与收藏

<ol><li>密码库顶部搜索按条目名称或账号筛选；记事本按标题或正文筛选。密码库和记事本各自保留查询。</li><li>单击搜索框右侧清空按钮恢复全部结果。最多输入 128 个 Unicode 字符；超过后先缩短内容，再继续搜索。</li><li>使用“全部”“收藏”等筛选，或名称、最近更新等排序。无结果时先清空查询并检查是否仍有筛选条件。</li><li>点击星标加入或取消收藏；排序或筛选改变后条目可能移动，不表示被删除。</li></ol><h3>出错后怎么办</h3><p>检查当前连接的数据库是否正确。修改名称后请用新名称搜索；遇到未保存记事提示，应先处理草稿。帮助和设置页面不会把全局搜索变成手册搜索。</p>

## 新建与编辑记事

<ol><li>连接数据库，进入“记事本”，单击新建入口。</li><li>填写标题和正文并保存。成功后卡片出现在记事列表；展开卡片阅读正文。</li><li>进入编辑状态修改内容，单击保存后才写入数据库。可以收藏、搜索、排序和翻页。</li><li>删除前核对标题并确认；重要内容应先备份。</li></ol><h3>出错后怎么办</h3><p>有未保存修改时，切页、搜索或离开可能要求先处理草稿；选择继续编辑可保留输入。保存错误时保留窗口，按提示处理后重试。锁定、退出或安全恢复会清除可见敏感内容，不能把未保存草稿当作持久记录。超长旧记事按界面提供的滚动或完整内容入口阅读，不应为显示方便而截断保存。</p>

## 安全体检与修复

<h3>检查与处理</h3><ol><li>连接数据库后进入“体检”，查看弱密码、重复密码和长期未更换项目。</li><li>进入某类问题查看对应条目，再逐项打开记录核对。</li><li>更换网站或应用的真实密码后，再把新的密码保存到小仓；只修改小仓记录不会修改外部账号。</li><li>回到体检，必要时重新扫描，核对问题是否已消失。</li></ol><h3>结果如何理解</h3><p>长期未更换按设置中的阈值判断；强度与预计破解时间只是基于模型的提示。全量体检可能在后台处理，按界面进度等待；普通导航不会要求你重新开始全部工作。</p><h3>出错后怎么办</h3><p>记录被其他操作删除或修改时，重新打开最新列表。不要把“没有发现问题”理解为安全认证；不认识的账号变更应先到对应服务核查。</p>

![安全体检与修复](images/health_zh.png)

## 生成密码与强度检测

<ol><li>进入“工具”，选择密码生成，设置长度及大小写、数字、符号等字符集合。</li><li>长度可为 1–1024；至少启用一种字符集合。生成后核对长度及目标网站的限制。</li><li>单击复制，把结果用于相应账号；生成和复制不代表已存入数据库，需要另行保存记录。</li><li>切换到强度检测，输入待评估内容，阅读评级、风险及建议；不要把长时间估计当作保证。</li></ol><h3>出错后怎么办</h3><p>输入超出限制或字符集合为空时按提示修正。复制失败时不应认为系统剪贴板已经更新。工具在未连接数据库时也可使用，但锁定或退出会清除敏感结果。</p>

![生成密码与强度检测](images/tools_zh.png)

## 快速搜索条

<h3>搜索与复制</h3><ol><li>在设置中启用快速搜索条，使用显示的全局快捷键唤出；默认是 Alt+P。</li><li>输入条目名称或账号，按上下方向键选择。按 Enter（回车）复制密码，Ctrl+Enter 复制账号；也可用结果中的对应按钮。</li><li>未连接时先回主窗口连接数据库，再搜索记录。</li></ol><h3>快速生成</h3><p>输入 <code>gen</code> 生成默认 20 位随机密码，或输入 <code>gen 32</code> 指定 32 位；支持 4–1024 位。按 Enter 生成并复制，成功后原位显示“已复制”，搜索条与输入保持打开。它不会自动创建记录。</p><h3>出错后怎么办</h3><p>快捷键无效时检查功能开关及是否与其他软件冲突，到设置重新录制可用组合。没有结果时清空查询并核对当前库。自动隐藏时间在设置中调整；手动关闭可用 Escape（退出键）。</p>

## 加密备份与恢复

<h3>导出备份</h3><ol><li>先连接要备份的数据库，进入“设置”，找到“导入导出数据”，单击右侧“打开”。</li><li>选择导出、所需范围和目标路径；设置一个<strong>非空的备份密码</strong>，按要求再次确认。</li><li>单击“开始导出”，看到成功提示后核对目标文件存在。把备份密码单独妥善保管。</li></ol><h3>从备份恢复</h3><ol><li>先备份当前数据库；建议先在新建的空数据库中尝试恢复。</li><li>进入同一入口选择导入，选择小仓加密备份并输入该备份的密码。</li><li>单击窗口底部的“预览”，先确认密码冲突，再确认记事冲突；没有对应冲突的步骤会略过。每步的批量按钮只影响该类记录，可返回密码步骤修改而保留记事决定。全部确认后，单击一次“开始导入”。</li><li>成功后回密码库和记事本核对结果；取消、验证失败或预览本身都不算导入完成。</li></ol><h3>冲突与错误</h3><p>跨库密码记录的同名冲突按原始名称逐字精确匹配，账号只帮助辨认，不能当作冲突判据。备份密码错误、文件损坏、格式或版本不支持时停止并保留原文件，核对所选文件与密码。不要反复改后缀或编辑备份内容来绕过验证。导入不是任意 CSV、明文或其他密码软件格式转换。</p><p>覆盖会替换同名密码记录的全部字段；跳过保留目标。记事会检查完全同名和仅大小写或空白不同的标题，可保留两份、跳过，或明确选择目标后覆盖。多个目标可用“上个目标／下个目标”查看；同一目标不能被多篇导入记事同时覆盖。“全部覆盖”会留下有歧义的记事供逐项处理；“全部保留两份”保留现有记事，并为本次导入的每篇记事新增副本。加密备份仅包含所选的密码和记事，不包含软件设置等本机应用数据。需要换文件或密码时，选择“返回文件与密码”，重新选择文件、输入密码并预览。</p><p>导入／导出在独立窗口中打开，可拖动边框调整大小或最大化。预览列表独立滚动，批量操作、待处理数量、错误提示和最终操作始终留在窗口中。重新预览包含记事的备份时，需要重新确认处理方式。</p>

## 设置、锁定与退出

<p>在设置页使用顶部搜索栏，可按设置名称、说明或分组名筛选，例如“剪贴板”。清空恢复全部；无匹配时更换关键词。最多128个字符，超限保留输入并提示。未连接也能搜索，但设置原有的使用条件不变；离开设置后查询清空。</p><h3>常用设置</h3><p>“设置”提供主题（浅色、深色、跟随系统）、中英文、90/100/110/125 字号、侧栏文字、默认视图、启动路径填充、关闭行为、自动锁定、剪贴板清理、快速搜索条及当前数据库操作。以每项实际范围和错误提示为准；保存失败时修改不会被当作已生效。</p><h3>锁定与托盘</h3><p>侧栏锁定会断开当前库并清除敏感显示；自动锁定和系统睡眠也会触发相应安全处理。默认关闭窗口会缩到托盘，<strong>不等于退出或锁定</strong>。需要结束软件时使用托盘的退出入口。白色完整版托盘图标表示已连接，收拢版表示未连接或锁定，可查看悬停文字。</p><h3>剪贴板与退出错误</h3><p>复制后按你的清理策略处理剪贴板；系统历史、同步或其他程序已读取的副本不受软件撤回控制。如果退出提示剪贴板清理失败，可重试，或在了解提示后明确确认退出；切勿将这种退出理解为剪贴板已清空。</p><h3>修改主密码</h3><p>先备份，在当前数据库的改密入口填写所需密码并确认。成功后以后使用新主密码开库；旧备份仍使用各自的备份密码。失败时按界面状态重新连接并核对，不凭猜测删除原文件。</p>

## 迁移、更新与卸载

<h3>通过加密备份迁移</h3><ol><li>在原设备上连接数据库，进入“设置 → 导入导出数据”，导出需要保留的密码和记事。妥善保管备份密码。</li><li>将加密备份带到新设备，在小仓中新建数据库，再导入备份。</li><li>核对密码和记事已完整恢复后，再决定是否清理原设备上的副本。</li></ol><p>加密备份用于迁移密码和记事。新设备上的主题、字号等软件设置可以按需重新选择。</p><h3>便携版：复制整个软件目录</h3><ol><li>正常退出所有正在使用该数据库的软件窗口。</li><li>复制整个便携版软件目录到目标位置。</li><li>保存在该目录之外的数据库需要另外复制。打开小仓后，选择目标位置的数据库并连接。</li><li>确认记录完整、软件可以正常使用，再处理原位置的文件。</li></ol><h3>更新、卸载或遇到问题时</h3><p>更新或卸载前，先制作并核对加密备份，保留自己的数据库和备份文件，再按照发行说明操作。</p><p>迁移失败或遇到无法解决的问题时，请先保留原文件，并通过“帮助 → 关于”中的项目地址到社区求助。说明软件版本、操作经过和错误提示即可；请勿提交真实密码、数据库、备份或含敏感信息的截图。</p>
