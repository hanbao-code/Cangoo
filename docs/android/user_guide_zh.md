# 小仓安卓版 1.0.0 使用手册

[English](user_guide_en.md) · [项目首页](../../README.md) · [版本说明](../../release_notes.md) · [第三方来源与许可](../../third_party/android/README.md)



## 第一次使用与创建密码库

1. 首次打开时阅读许可说明，选择继续，按引导进入“我的密码库”。
2. 点击“新建密码库”，填写名称和主密码，再输入一次主密码确认，点击“创建密码库”。创建后即可保存资料。
3. 下次使用时选择这个库，输入它自己的主密码解锁。密码库可分开保存个人、工作等资料。

主密码区分大小写，前后空格也算密码的一部分。主密码留空时，任何能操作小仓的人都可打开这个库，也无法启用快捷解锁。建议设置只有你知道的主密码。
密码库保存在这台手机上。小仓不提供主密码或备份密码找回功能，请分别妥善保管。定期导出加密备份，将备份密码与文件分开保存。手机卸载小仓、清除应用数据或重置后，应用内的密码库会被删除。

## 添加、编辑与删除资料

1. 在“常用”或“全部”页点击＋，选择“新增密码”或“新增记事”。
2. 密码记录填写名称、账号和密码，可补充备注；记事填写标题和正文。点击“保存密码”或“保存记事”才会写入密码库。
3. 再次打开记录，核对内容。需要修改时点“编辑”，修改后保存；需要删除时在编辑页选择删除并确认。删除后不能直接撤销，重要资料请先备份。

编辑普通密码字段时，清空后保存会把密码改为空，不表示保留旧密码。更新网站或应用的密码时，先在对应服务修改成功，再更新小仓；小仓不会替你修改外部账号。
若保存失败，按提示修正或重试；若提示记录已变化，先核对最新内容，再决定是否放弃当前草稿。

## 查找、收藏与排序

“常用”展示收藏和最近打开的资料。在记录详情点星标可收藏或取消收藏。
“全部”可切换密码、记事，并按收藏筛选；密码还可筛选弱密码和相同密码。使用“最近更新”或“名称顺序”调整列表顺序。
点击搜索按钮，输入名称、账号或记事正文中的文字。搜索不会查找密码、动态口令密钥或恢复码。找不到记录时，先核对当前密码库，再清除搜索文字或筛选条件。

## 动态口令与恢复码

动态口令：在密码记录的新增或编辑页开启“动态口令”，填写对应服务提供的“动态口令设置密钥”，保存后在详情查看、复制当前口令。不要把当前显示的验证码当作设置密钥。口令被服务拒绝时，核对服务设置和手机时间。
恢复码：把服务提供的恢复码一行一个填入记录并保存。在详情按需显示、复制单条；用完后点“标记已用”，误标可点“撤销已用”。这个标记只帮助你记住哪些码已经用过，不会改变对应服务中的使用状态。
已有密钥或恢复码默认保留。要更换时点“替换”；替换输入留空仍保留原有内容。要删除时明确点“移除”，保存后生效。替换整组恢复码会重置本地已用标记。

这些恢复码用于对应网站或应用，不能用来找回小仓的主密码。

## 生成密码与单次强度检查

1. 在“工具 → 生成密码”选择长度和字符类别，至少保留一种类别，再生成密码。
2. 可查看、复制结果，或点“用于新记录”带入密码表单，补全信息后保存。表单中的“生成密码”也可直接填入；“参数”用于调整并记住生成设置，不改动已填密码。
3. 只想检查一段密码时，打开“工具 → 检查密码强度”，输入后分析，查看结果和建议；结束后清空或返回。

生成或复制不等于保存，也不会修改外部账号。工具生成结果默认1分钟后清空，可在设置中调整或关闭；查看、复制不会延长时间，修改设置从下一次生成生效。清空工具结果不影响已填入表单或已保存的密码。
强度分析在本机完成。评分和预计破解时间只是估计，仍应为不同账号使用不同密码。

## 检查密码库中的密码

打开“工具 → 密码检查”，查看当前库的弱密码、相同密码和待检查项。点有提示的记录查看详情，需要时到对应服务修改密码，再编辑小仓中的记录。
保存记录会先完成，强度评级随后更新。尚未检查或检查失败的项目还没有可用结果；按页面提示继续检查或重试。主动取消后，需点“继续检查”恢复，保存新记录不会代替这一步。
没有填写密码的记录不参与检查。检查结果是帮助你排查的提示，不是账号安全保证。

## 创建加密备份

1. 解锁要备份的库，进入“设置 → 备份与恢复”，也可从“工具 → 备份与恢复”进入，选择“创建备份”。
2. 核对当前库，选择“全部资料”“仅密码”或“仅记事”，为这份备份设置单独的密码，再输入一次确认。备份密码不能留空。
3. 点击“创建备份”，在系统文件选择器中选择本机保存位置。看到“备份文件已保存”后核对文件；建议另建一个没有资料的密码库，试着恢复这份备份，确认文件和密码都可用。

备份包含所选记录的内容，不包含主密码、软件设置，也不会迁移指纹或人脸快捷解锁。打开这份备份需要导出时设置的备份密码，请与文件分开保管。换机或在电脑版与安卓版间迁移时，使用加密备份或设备传输，不直接互换密码库文件。
失败或取消可能留下空文件或不完整文件，按提示到文件管理器核对。“本机最近备份”只记录上次操作，不保证文件仍在或可恢复。

## 恢复备份与比较差异

先确定要把资料导入哪个密码库。这个库已有资料时，先为它创建备份；也可新建一个空库尝试。
1. 解锁这个库，在“备份与恢复”选择“从备份恢复”。选择本机备份文件，输入这份备份的密码，点“预览内容”。大备份的首次读取可能较久，动态小点表示仍在处理。
2. 核对目标库和待导入的密码、记事。没有对应项的资料将新增，相同内容自动跳过。点记录查看两侧差异；需要查看密码等隐藏内容时，点对应的“显示两侧”。长备注或正文可点“展开完整对照”分段阅读。
3. 对两边内容不同的记录，选择“保留当前”或“覆盖当前整条”。记事也可新增备份中的这篇，保留当前记事。若有多篇相近记事，先选择要对照的当前记事，再明确决定是否覆盖；切换对照本身不改变之前的决定。
4. 可按处理状态和变化字段筛选。底部“选择范围”可全选本页，或“全选当前筛选（跨页）”，然后用“批量处理”选择处理方式并确认应用。更换筛选不会取消之前勾选的项目，批量确认时还要核对当前列表外的已选项。需要逐项核对的记事会保留原决定，请打开详情分别处理。
5. “待处理”为0后，核对新增、覆盖和跳过数量，点“确认恢复”并作最后确认。小仓此时才会将选定资料写入密码库。完成后查看实际记录；取消预览则丢弃这次选择。

覆盖会替换整条记录，不能只恢复其中某个字段；备份没有的其他当前记录不会删除。若备份中的这条记录不含恢复码，覆盖会清空当前恢复码及已用标记，先看清提示。恢复旧备份时，已用标记也会回到备份时的状态，请重新核对实际使用情况。选择“保留当前”可避免覆盖。
比较时的点击和滚动会重新计算空闲时间；一直不操作时，仍按自动锁定设置锁库，没有额外的预览时限。关闭、取消、锁库或切库后需重新预览。密码错误、文件损坏或资料已变化时，按提示核对并重试。
文件选择器看不到文件时，可从“手机内部存储”进入实际保存目录。选择文件期间若锁库，按提示解锁原目标库，重新输入备份密码后继续；切库后需重新开始。

## 向附近设备发送或接收资料

1. 两端分别解锁本次使用的密码库，进入“设置 → 设备传输”。一端选“发送资料”，另一端选“接收资料”，并选择相同连接方式。两库名称无需相同。
2. 使用局域网时，两端连接同一Wi-Fi，或连接一端手动开启的热点。电脑若提示未授权，先在电脑端点击“允许本地设备连接”并确认系统提示。使用经典蓝牙时，先在系统设置中配对，保持蓝牙开启，并按系统提示允许连接所需权限。
3. 接收端先点“开始等待接收”（电脑版为“等待发送方”）。看到接收端已进入等待状态后，发送端点“查找接收设备”（电脑版为“查找附近设备”）并选择对方。
4. 核对两端显示的三组数字。完全相同才在两端分别确认；不同就取消。
5. 发送端选择要传的资料范围，点“准备资料”（电脑版为“确认范围”）。
6. 接收端核对两边的密码库、传输方向和资料数量，点“接受本次接收”（电脑版为“同意接收”）。接收端同意后，发送端再点“开始发送”（电脑版为“开始传输”）。
7. 接收端完整收到并校验资料后，按上一节比较差异并确认导入。发送端此时可以离开；对方已收到资料，不代表已经导入密码库。

未发现局域网设备时，发送端可展开“手动连接”，输入接收端等待页显示的IPv4地址，不填端口，再点“连接设备”。仍连不上时，核对接收端是否还在等待、两端的网络或系统配对状态，也可换用另一种连接方式。
一次传输只把资料从发送端交给接收端，不会自动让两库保持一致。发送端资料不变，接收端原有但本次未传送的记录也不会删除。主密码、软件设置和快捷解锁配置不传送。
实际收发和校验期间，空闲自动锁定和离开时立即锁定会暂时停用，仍请尽量保持前台。手机锁屏、主动锁库、切库或退出会中止。传输结束后重新计算空闲时间，比较阶段按正常设置锁库。若中断或校验失败，需要重新等待、连接并核对新的验证码，不会自动接着传。

## 管理密码库与修改主密码

在“设置 → 管理密码库”中可新建或选择另一个库，切换前先保存草稿。当前已解锁库有“修改名称”入口；按提示输入该库主密码并保存。
修改主密码：先备份，再进入“设置 → 修改主密码”，输入当前主密码，再输入两次新主密码，点“修改并锁定”。修改成功后密码库会锁定，用新主密码即可解锁。之前导出的备份仍使用各自原来的备份密码。新主密码留空会取消主密码保护并关闭快捷解锁。
删除密码库：在库列表点“删除密码库”，验证该库主密码，再核对名称和资料数量，确认删除。此操作删除该库全部资料，不能直接撤销，不会用其他库的主密码代替确认。
若修改或删除后提示结果无法确认，先按提示重新读取库列表，或重新解锁查看实际结果。保留现有资料，不要通过反复删除或清除应用数据来处理。

## 设置指纹或人脸快捷解锁

1. 先用主密码解锁要设置的库，进入“设置 → 快捷解锁”。
2. 这个库必须已设置主密码。输入该主密码，点“启用快捷解锁”，完成系统指纹或人脸验证。每个库需分别启用。
3. 以后可在该库锁定页使用快捷解锁；需要停用时回到同一设置入口关闭。

可用方式以系统提示为准。只有达到系统安全要求的指纹或人脸识别可用于快捷解锁，不能用手机锁屏密码、图案或PIN代替。识别不可用或失败时，用该库主密码解锁。
换机或通过备份迁移资料后需重新启用；请仍记住主密码并保留备份，不要只依赖生物识别。

## 锁定、切换应用与退出

暂时离开前，可点页面上的锁图标，或在设置点“立即锁定”。默认连续5分钟没有操作就会自动锁定，切到后台的时间也计入；可在设置修改“空闲自动锁定”。
“离开时立即锁定”默认关闭。普通切换应用会隐藏页面，未触发锁定时返回可继续；开启该设置后，切应用或进入最近任务就会锁定。手机锁屏、手动锁定或切换到另一个密码库时，未保存的草稿会被清除，请先保存。
需要退出时，在“常用”页按系统返回，锁库并回到“我的密码库”；在库列表按提示再次返回退出。按Home回手机桌面只是切到后台。
锁定后需重新解锁；之前的备份预览或传输比较不会自动重新打开。传输时暂停自动锁定的具体规则见“向附近设备发送或接收资料”。

## 复制内容与清空剪贴板

在记录详情使用对应复制按钮，再尽快粘贴到需要的位置。敏感内容默认隐藏，需要时再显示；复制不要求先把内容显示出来。
在设置调整“复制内容保留”为5、30或60秒，小仓到时尝试清空当前剪贴板；也可在有待清理内容时点“清空剪贴板”。修改时长从下一次复制生效，关闭提示不会取消清理。
清空可能影响你随后从其他地方复制的内容。“已尝试清空”表示发出了请求；系统限制或应用被关闭时，不保证按时清空。输入法、系统历史或其他应用保存的副本不会一并删除，请到对应软件管理。

## 调整显示与系统设置

在“设置”中调整“语言 / Language”“文字大小”和“外观”。外观可选主题配色及明暗模式；按页面提示选择或保存，返回后继续使用。锁库时也可从齿轮进入这些通用设置与使用帮助。
“权限与系统设置”可查看本应用的系统状态，并按需进入手机设置。设备生物识别可用不代表当前库已经启用快捷解锁，仍需单独配置。
若状态无法读取，在系统设置中确认。省电或后台限制可能影响后台运行，传输尽量保持前台；页面显示正常也不保证所有手机都允许持续后台运行。

## 检查更新、阅读帮助与求助

联网后，在“设置”或“使用帮助 → 关于小仓”点“检查更新”。自动检查默认开启，间隔1天（24小时）。距离上次检查满设定天数后，小仓会在下一次启动时检查；即使上次失败，也从那次检查起计算。可修改间隔，关闭自动后仍可手动检查。
发现新版时可查看说明与发行页，选择7天内不提醒或本版不再提醒；这些选择只影响本机该版本的自动提示。检查失败可重试，失败不等于已是最新。版本检查联网读取GitHub上的公开发行信息，请求不包含密码库内容或主密码。下载与安装由你决定。
“使用帮助”还可重新阅读开源许可和第三方声明；“关于小仓”的联系入口由系统浏览器或相应应用打开。
更新、换机、卸载或清除应用数据前，先制作并核对独立加密备份。遇到问题，请提供软件版本、操作步骤和不含秘密的错误提示，不发送真实密码、密码库、备份文件或敏感截图。

安全问题请按[安全问题报告说明](../../SECURITY.md)提交。
